# 📊 Sales Analysis Dashboard

## 📌 Project Overview

This project is an interactive Sales Analysis Dashboard developed using Power BI. The dashboard provides a comprehensive view of sales performance, costs, profitability, units sold, and country-level performance.

## 🎯 Project Objective

The objective of this dashboard is to transform sales data into meaningful business insights and help users analyze sales performance through interactive visualizations and filters.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Data Analysis
- Interactive Dashboard
- KPI Reporting

## 📈 Key KPIs

- Units Sold: 155.32K
- Total Cost: 40.38M
- Total Sales: 19.04M
- Profit: -21.34M
- Profit Ratio: -52.86%

## 📊 Dashboard Features

- Monthly Sales Analysis
- Monthly Units Sold Analysis
- Country-wise Profit Analysis
- Total Cost Analysis
- Interactive Year Filter
- Country Filter
- Product Filter
- Segment Filter
- KPI Cards for quick performance monitoring

## 🔍 Key Insights

- Total sales are 19.04M against a total cost of 40.38M.
- The dashboard indicates a negative profit of 21.34M.
- The overall profit ratio is -52.86%.
- Monthly sales performance varies significantly throughout the year.
- October records the highest monthly units sold among the displayed months.
- Country-level analysis helps identify differences in profitability across markets.

## 💡 Business Value

This dashboard can help business users monitor key performance indicators, identify sales trends, analyze profitability, and make data-driven decisions.
